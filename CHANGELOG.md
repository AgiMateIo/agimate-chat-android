# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[semver](https://semver.org/lang/ru/). Номер сборки выводится из версии, по три разряда на
поле: `0.3.1` → `3001`.

Записи тезисные: строка на изменение, причина — только там, где без неё непонятно. Подробности
живут в коде и в истории коммитов.

## [0.3.4] - 2026-08-25

### Fixed

- Отправка файла в переписку: загрузка идёт в общий `/manage/files`, вебчатовский эндпойнт удалён
  на сервере.
- Протухшая за 15 минут подпись больше не выглядит потерянным доступом: ссылка перезапрашивается,
  и картинка дорисовывается сама. Ушедшим по сроку файл считается, только если его нет в листинге.

### Changed

- Список файлов из переписки показывает её вложения — и присланные, и произведённые в ней; фильтр
  по агенту сменил смысл на «связан с агентом» и больше не используется.
- Со скрепки предлагаются все свои файлы, а не файлы одного агента.
- У загрузки есть метка происхождения: файл из переписки виден в листинге как `user:chat`.

## [0.3.3] - 2026-08-24

### Added

- Вход по почте и паролю — рядом с провайдерами.
- Регистрация и «забыли пароль»: приложение шлёт письмо, пароль назначается по ссылке из него.
  Ссылка ведёт на веб — App Link ещё выключен.
- Экран «способы входа» в профиле: провайдеры и пароль одним списком, привязка, смена и удаление
  пароля. Открыт и роли `GUEST`.
- Привязка провайдера в два шага: круг с `link=1` даёт доказательство, аккаунт называет следующий
  запрос.
- Обновление токена заранее, на девяти десятых срока; срок — из `expiresIn` ответа.
- Глазок у поля пароля.
- Длина пароля проверяется в байтах UTF-8: граница в 72 байта, а не в символах.

### Changed

- Экран входа собран заново: форма выше кнопок провайдеров.
- Вход через VK не предлагается: кнопки нет ни на входе, ни в привязке. Уже привязанный VK
  остаётся в списке способов входа и отвязывается.
- Возврат из браузера различает вход и привязку: `code` против `link_proof`.
- Вход по паролю представляется `NATIVE` явным полем: значение по умолчанию наш `Json` не пишет.
- Аргументом строки бывает другая строка из ресурсов.

## [0.3.2] - 2026-08-23

### Added

- Рассказ о приложении: три слайда перед входом, листаются свайпом и кнопкой, пропускаются с
  любого. Показываются один раз и только тому, кто не вошёл.
- Отметка о просмотре — номер версии интро, а не «да»: показать его заново будет правкой одной
  константы.
- Иллюстрации слайдов собраны из словаря знака — ромб на диагональной сетке 45°.
- Указатель «‹ Интро» в левом верхнем углу входа: перечитать рассказ, не трогая отметку.
- Свой экран настроек — язык, тема и адрес сервера в одном месте; открывается шестерёнкой на входе
  и строкой в профиле. До входа они нужны не меньше, чем после.

### Changed

- Фон — градиент и два пятна света вместо плоской краски. Все три краски лежали в токенах
  айдентики с самого начала.
- Одного градиента для этого мало: одиннадцать уровней яркости на высоту экрана глаз без края не
  ловит. Градиент — грунт, красят пятна; их центры вынесены за холст.
- На интро, входе и ожидании одобрения пятна медленно вращаются: периоды 13, 17 и 21 с — без
  заметного общего кратного. При выключенных в системе анимациях не заводятся вовсе.
- Под лентой сообщений подложка неподвижна намеренно: ползущее пятно меняло бы контраст текста.
- Шапки чата и списка контактов лишились своей заливки — они не слои поверх ленты.
- Экран входа собран по центру вместо отступа в 72 dp сверху.
- Строка под знаком: «Возложите рутину на ИИ-агентов» вместо «Напишите — и они сделают».

## [0.3.1] - 2026-08-22

### Changed

- Знак по обновлённому бренд-буку: один шеврон вместо двух, радиус 6,5 вместо 5, габарит
  72,66 × 66,09. Нижний шеврон переставал различаться уже около 48 px.
- У каждой фигуры свой градиент по диагонали 45° вместо чередования двух красок; порог плоской
  заливки поднят с 24 до 40 dp.
- Иконка приложения — плита-градиент с тёплым бликом Mocha Mousse вместо плоского акцента; ради её

- Номер сборки выводится из `versionName`, по три разряда на поле. Раньше номер и версия велись
  порознь — тот случай, когда однажды поднимают одно и забывают второе.

## [0.3.0] - 2026-08-22

### Added

- Своя отправка возвращает ленту в конец. Для входящих правило прежнее: ушедшему читать историю
  ленту не дёргают.
- Айдентика v1: тёплые нейтрали Mocha Mousse и бирюзовый акцент вместо угля и золота, знак из
  ромбов и шеврона, IBM Plex Sans и Mono вместо системной гарнитуры.
- Цвета, радиусы и длительности — из `com/agimate/design/AgimateTokens.kt`, копии сгенерированного
  файла айдентики. Копия намеренная: смена токена — правка в трёх репозиториях, забытую третью
  ловит `tools/check-tokens.sh`.
- Четыре роли смешиваются из существующих: пузыри, приглушённые заливки, текст третьего плана и
  акцент для мелкого текста — бирюза на тёмной теме даёт контраст 4,32, ниже порога.
- Гарнитура подменена и в `Typography` для material3, иначе меню, диалоги и поля остались бы на
  системной. Шрифты переменные, кириллица в файлах: русский — основная локаль.
- Выбор темы: без явного выбора приложение следует телефону, явный перебивает. Применяется
  подменой конфигурации, а не флагом — от `uiMode` зависят ресурсы `values-night`, откуда берётся
  фон окна.
- Выбор языка отдельно от языка телефона. С Android 13 его хранит система (`LocaleManager`), до
  13 — SharedPreferences и подмена конфигурации у активности и у приложения. Своей копии рядом на
  13+ нет намеренно: выборы разошлись бы.
- Русский и английский: база английская, `values-ru/` переопределяет — устройство с чужой локалью
  получает английский, а не русский.
- Строк для человека в коде не осталось: вниз едет `UiText`, разворачивается на экране. У
  исключений два текста — `text` для человека и непереводимый `message` для логов.
- `Accept-Language` к каждому запросу к API: выбранный язык первым, предпочтения телефона следом.
  Файловый клиент заголовок не шлёт — за ссылкой лежит содержимое файла.
- Даты собираются по `Locale.getDefault()` в момент показа: порядок «день-месяц» спрашивается у
  системы, а не придумывается.
- Текст ошибок от сервера показывается как есть: сервер знает про отказ то, чего клиент знать не
  может — лимиты вложений приходят числами в тексте.
- Длинные анимации слушают настройки телефона — аналог `prefers-reduced-motion`. Правило
  распространяется на любую новую длительную анимацию.
- Поделиться сообщением, открыть, сохранить и отправить вложение; те же действия кнопками в
  полноэкранном просмотрщике.
- Наружу уходит копия файла в кэше через FileProvider, а не подписанная ссылка: чужому приложению
  нужен файл, а не право сходить за ним от нашего имени. Качает её клиент без интерсепторов.
- «Сохранить»: картинки в галерею, остальное в «Загрузки», в папку `AgiMate`. С Android 10 —
  MediaStore без разрешений, на 8 и 9 разрешение спрашивается в момент нажатия.
- Имя файла приходит из чужих рук и чистится: путь вырезается, запрещённые символы заменяются.
- 401 и 403 по ссылке на файл названы «ссылка устарела — откройте чат заново»: почти всегда это не
  «нельзя», а «чат открыт давно».
- RTL остаётся выключенным (`supportsRtl="false"`): среди двух языков ни одного справа налево нет.

### Fixed

- Переписка не дёргается при появлении клавиатуры: `reverseLayout` переворачивает порядок, но не
  аррангемент, и голый `spacedBy` паковал сообщения к верху.
- Заодно ушла полоса фона высотой с навбар: вставка клавиатуры навигационную панель уже включает.
- Картинка в переписке не толкает историю: пропорция запоминается по `fileId`. Размеров вложения
  сервер не отдаёт — настоящее лечение в контракте.
- Запуск на запертом телефоне: `PushSync` внедряется как `Lazy` и поднимается по
  `ACTION_USER_UNLOCKED` — за ним тянется граф до токенов, недоступных до первой разблокировки.

## [0.2.0] - 2026-08-19

### Added

- Пуш-уведомления о сообщениях агента; транспорт — RuStore `universalpush`, FCM и HMS добавляются
  своими провайдерами.
- Подписка принадлежит входу: регистрируется при входе и при ротации токена, на запуске процесса —
  не чаще раза в сутки.
- Все три повода сведены в одну сверку с единственным отправителем: `getTokens()` сам поднимает
  колбэк «новый токен», и два отправителя зарегистрировали бы его дважды.
- Выход снимает подписку до очистки токенов доступа; вход, с которого подписку сняли, больше не
  регистрируется до смены входа.
- Уведомление подавляется, если переписка открыта на экране, — но только когда приложение видно.
- Идентификатор уведомления — по переписке; дубли отсекаются по `messageId` до показа.
- Тап открывает чат и ждёт, пока навигация будет готова: пуш приходит и когда профиль ещё грузится.
- Контракт — в `docs/push-notifications.md`. Без `RUSTORE_PROJECT_ID` транспорт не поднимается,
  приложение работает как раньше.
- «Уведомления приходят» на экране устройств: по своей строке приложение сверяет `maskedToken` с
  началом токена из SDK — единственный симптом сломанной подписки иначе тишина.
- Расхождение чинится перерегистрацией, одна попытка на открытие экрана.
- Пока транспорт не отдал токен, строка говорит «настраиваем уведомления»: это незаконченная
  настройка, а не поломка.
- Список входов открыт аккаунту в ожидании одобрения: потерявшему телефон отзыв нужен раньше, чем
  администратор дойдёт до заявки.

### Fixed

- Отзыв устройства сверяется с сервером: `404` перечитывает список, `403` ведёт к локальному
  выходу. Раньше приложение оставалось с мёртвыми токенами в открытом продукте.

## [0.1.0] - 2026-08-18

Первый выпуск: `versionCode 1`, `versionName 0.1.0`, тег `v0.1.0`. Всё, что накопилось до него,
собрано здесь.

### Fixed

- Абсолютная ссылка на файл склеивалась с origin: пресайненные ссылки приходят вперемешку с
  относительными путями, картинка молча не грузилась.
- Созданный агент не получал ни навыков, ни коннекторов: привязка навыка доступа к коннектору не
  даёт, его открывает отдельный запрос. Мастер помнит id агента и продолжает с упавшего шага.
- Живые сообщения не доходили в открытый чат: подмена хоста WebSocket нужна локальному стенду, а у
  настоящего сервера Centrifugo стоит на своём хосте. Включается по адресам, а не по флагу сборки.
- Сообщение, пришедшее во время загрузки истории, пропадало: история подкладывается под живое.
- Упавшая подписка умирала молча: на постоянной ошибке библиотека не повторяет. Подписка
  поднимается заново, пока канал кому-то нужен.
- Второй экран той же переписки не получал ничего: канал мультиплексируется между читателями.
- Ложная полоска «Связь потеряна» поверх исправного соединения.
- Открытие чата тянуло всю историю страница за страницей: `derivedStateOf` захватывал число
  элементов из первой композиции.
- Падение списка на повторяющемся ключе: все три идентификатора сообщения необязательны.
- Сообщение без времени в середине ленты давало два разделителя одной даты.
- Сообщения мигали при скролле: разбор markdown теперь синхронный, анимация размера блоков
  выключена.
- Пузырь с картинкой подпрыгивал в момент загрузки: место занимает скелетон.

### Added

- Просмотр картинки на весь экран: щипок и двойной тап до 5×, перетаскивание в границах, выход по
  «назад», крестику или тапу.
- Мультиплексирование канала переписки с подсчётом читателей: одна подписка независимо от числа
  экранов, последний уходящий её снимает.
- Экспоненциальный backoff с пробуждением по возврату сети: пауза растёт с 3 с до минуты, но
  обрывается, как только `NetworkMonitor` сообщает о сети.
- `RetryInterceptor` — повтор на `5xx` и `429`, только для `GET` и `HEAD`: отправка сообщения не
  идемпотентна, слепой повтор задвоил бы реплику.
- Наблюдаемость real-time в отладочной сборке: состояние подписки, коды разрывов, причины
  неразобранных публикаций.

### Changed

- Имя канала берётся из ответа на запрос токена: токен — грант ровно на тот канал, что назвал
  сервер, разойдись имена — Centrifugo молча отвечает «нет прав».
- Полоска промежуточного шага заменена заготовкой ответа в ленте: полоска забирала высоту и дёргала
  ленту на каждом обновлении шага.
- Новые сообщения появляются анимацией; проявление — только нижнему элементу, иначе лента мигала бы
  на каждом листании вверх.
- Полоски состояния раскрываются, а не возникают встык.
- Лента и признак работы агента обновляются одним разом: двумя обновлениями лента подпрыгивала.
- Логи real-time не попадают в релиз: они несут идентификаторы сессий и пользователя.
- `HttpLoggingInterceptor` в отладке поднят до `HEADERS` с вычеркнутым `Authorization`; в релизе
  по-прежнему молчит.
- `stop()` закрывает клиент Centrifugo через `close()`: `disconnect()` оставлял живыми executor,
  scheduler и пул соединений.
